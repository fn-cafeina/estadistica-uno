# Estadistica Uno

Proyecto de Estadística Introductoria. Ingeniería en Sistemas, UNAN-León. 3er año, II semestre, 2026.

**Tema:** Uso de la tecnología y rendimiento académico universitario.

Aplicación web educativa para explorar una base de datos y analizarla con procedimientos estadísticos, presentando los resultados en tablas, gráficos e interpretaciones.

## Desarrollo

Requiere Bun 1.3 o posterior.

```sh
bun install
bun run dev
bun run check
```

El entregable autocontenido se genera en `dist/index.html` y se abre directamente en el navegador.
